Du gène à la protéine fonctionnelle - La cellule eucaryote en détail

PARTIE A : LA TRADUCTION

Définition : Décodage de l'information contenue dans l'ARNm pour synthétiser une chaîne polypeptidique (protéine). C'est la dernière étape du dogme central : ADN → ARN → Protéine.

ARNm (codons 5'→3') → Protéine (acides aminés N-term → C-term)
Lieu : Ribosomes (cytoplasme ou RE rugueux)
Acteurs : ARNm + ARNt + Ribosomes + Facteurs protéiques

1. Le Code Génétique

Le code génétique est l'ensemble des règles qui définissent comment les séquences de nucléotides de l'ARNm sont traduites en séquences d'acides aminés.

A. Les Codons

  • Codon : Séquence de 3 nucléotides (triplet) qui code pour un acide aminé spécifique.
  • 64 codons possibles (4³ = 64 combinaisons).
  • 61 codons codent pour des acides aminés.
  • 3 codons stop (UAA, UAG, UGA) : signalent la fin de la traduction.
  • 1 codon start : AUG (code pour la méthionine, Met) → initie la traduction.

B. Les 4 Propriétés du Code Génétique

Propriété Signification Exemple / Conséquence
Universel Le même codon code pour le même acide aminé chez tous les êtres vivants (bactéries, plantes, humains). Permet le transfert de gènes entre espèces (OGM, thérapie génique).
Dégénéré (ou redondant) Plusieurs codons peuvent coder pour le même acide aminé. Ex: Leucine = 6 codons (UUA, UUG, CUU, CUC, CUA, CUG). Réduit l'impact des mutations.
Non chevauchant Les codons sont lus les uns à la suite des autres, sans se superposer. Ex: AUGCCG → AUG puis CCG (et non AUG, UGC, GCC...).
Sans ambiguïté Un codon donné code toujours pour le même acide aminé (jamais deux AA différents). AUG = toujours Méthionine (jamais autre chose).

💡 Astuce de prof - Piège classique :

Le code est dégénéré mais NON ambigu. Cela signifie :

  • Un acide aminé peut être codé par plusieurs codons (dégénérescence).
  • Mais un codon ne code JAMAIS pour deux acides aminés différents (pas d'ambiguïté).

Wobble (hypothèse de l'appariement oscillant) : Le 3ème nucléotide du codon (position 3') peut former des appariements non standards avec l'anticodon de l'ARNt → explique pourquoi plusieurs codons peuvent être reconnus par le même ARNt.

2. Les ARN de Transfert (ARNt)

Les ARNt sont les adaptateurs moléculaires qui font le lien entre le langage nucléotidique (codons) et le langage protéique (acides aminés).

A. Structure des ARNt

  • Taille : 73 à 93 nucléotides.
  • Structure secondaire en trèfle : 4 bras (accepteur, D, anticodon, TΨC).
  • Structure tertiaire en L : Pliage 3D compact.
  • Extrémité 3' CCA-OH : Site d'attachement de l'acide aminé (par liaison ester).
  • Anticodon : Séquence de 3 nucléotides complémentaire au codon de l'ARNm (lu dans le sens 3'→5' sur l'ARNt).

B. Le Chargement des ARNt (Aminoacylation)

Avant de participer à la traduction, chaque ARNt doit être "chargé" avec son acide aminé spécifique. Cette réaction est catalysée par une aminoacyl-ARNt synthétase.

ARNt + Acide aminé + ATP → Aminoacyl-ARNt + AMP + PPi
(Réaction en 2 étapes, catalysée par une synthétase spécifique)

⚠️ Important : Il existe 20 aminoacyl-ARNt synthétases (une par acide aminé), mais plus de 20 ARNt différents (car plusieurs codons pour un même AA).

💡 Astuce de prof - À retenir :

La fidélité de la traduction dépend de DEUX étapes critiques :

  1. Chargement correct de l'ARNt par l'aminoacyl-ARNt synthétase (reconnaissance AA/ARNt).
  2. Appariement correct codon-anticodon sur le ribosome.

Si la synthétase se trompe d'AA, l'ARNt sera mal chargé → mauvais AA incorporé dans la protéine.

3. Les Ribosomes

Les ribosomes sont les usines à protéines de la cellule. Ce sont des complexes ribonucléoprotéiques (ARNr + protéines).

A. Structure des Ribosomes

Critère Procaryotes (70S) Eucaryotes (80S)
Sous-unité petite 30S (ARNr 16S + 21 protéines) 40S (ARNr 18S + 33 protéines)
Sous-unité grande 50S (ARNr 5S + 23S + 31 protéines) 60S (ARNr 5S + 5.8S + 28S + 49 protéines)
Site de synthèse Cytoplasme Nucléole (assemblage) → export vers cytoplasme

B. Les 3 Sites Fonctionnels du Ribosome

Lors de la traduction, le ribosome possède 3 sites de liaison pour les ARNt :

  • Site A (Aminoacyl) : Site d'entrée du nouvel ARNt chargé.
  • Site P (Peptidyl) : Site où se trouve l'ARNt portant la chaîne polypeptidique en croissance.
  • Site E (Exit) : Site de sortie de l'ARNt déchargé (vide).

💡 Astuce de prof - Moyen mnémotechnique :

"A = Arrivée, P = Peptide (chaîne en cours), E = Exit (sortie)"

L'ordre de passage des ARNt est toujours : A → P → E.

4. Les 3 Étapes de la Traduction

A. L'Initiation

Procaryotes Eucaryotes
  1. La sous-unité 30S se fixe sur l'ARNm au niveau de la séquence de Shine-Dalgarno (en amont du codon start AUG).
  2. L'ARNt initiateur (ARNtfMet, chargé en N-formylméthionine) s'apparie avec le codon AUG dans le site P.
  3. La sous-unité 50S rejoint le complexe → ribosome 70S fonctionnel.
  4. Facteurs d'initiation : IF1, IF2, IF3.
  1. La sous-unité 40S reconnaît la coiffe 5' de l'ARNm et scanne jusqu'au premier codon AUG (règle de Kozak).
  2. L'ARNt initiateur (ARNtMet, chargé en méthionine non modifiée) s'apparie avec AUG dans le site P.
  3. La sous-unité 60S rejoint le complexe → ribosome 80S fonctionnel.
  4. Facteurs d'initiation : eIF1, eIF2, eIF3, eIF4, eIF5 (beaucoup plus nombreux que chez procaryotes).

💡 Astuce de prof - Différence clé :

Chez les procaryotes, le premier acide aminé est la N-formylméthionine (fMet). Chez les eucaryotes, c'est la méthionine (Met) standard. La forme est retirée dans les deux cas lors de la maturation de la protéine.

B. L'Élongation

Cycle répétitif qui ajoute un acide aminé à la chaîne polypeptidique. Chaque cycle comprend 3 étapes :

  1. Décodage (entrée de l'ARNt) : L'ARNt chargé approprié (reconnu par son anticodon) entre dans le site A. Nécessite le facteur d'élongation EF-Tu (procaryotes) ou eEF1A (eucaryotes) + GTP.
  2. Formation de la liaison peptidique : Le centre peptidyltransférase (activité catalytique de l'ARNr 23S/28S) transfère la chaîne polypeptidique de l'ARNt du site P vers l'ARNt du site A → nouvelle liaison peptidique.
  3. Translocation : Le ribosome se déplace d'un codon (3 nt) dans le sens 5'→3' sur l'ARNm. Nécessite le facteur EF-G (procaryotes) ou eEF2 (eucaryotes) + GTP. Conséquence :
    • L'ARNt déchargé passe du site P au site E → sort du ribosome.
    • L'ARNt portant la chaîne peptidique passe du site A au site P.
    • Le site A est maintenant vide, prêt à accueillir un nouvel ARNt.

C. La Terminaison

  • Le ribosome rencontre un codon stop (UAA, UAG ou UGA) dans le site A.
  • Aucun ARNt ne reconnaît ces codons → recrutement d'un facteur de libération (RF1/RF2 chez procaryotes, eRF1 chez eucaryotes).
  • Le facteur de libération provoque l'hydrolyse de la liaison entre la chaîne polypeptidique et l'ARNt du site P → libération de la protéine.
  • Dissociation du ribosome en ses deux sous-unités (nécessite le facteur RF3 ou eRF3 + GTP).

5. Les Polysomes et la Localisation des Ribosomes

Un polysome (ou polyribosome) est un ensemble de ribosomes traduisant simultanément le même ARNm → synthèse rapide de multiples copies d'une protéine.

Localisation des ribosomes dans la cellule eucaryote :

  • Ribosomes libres (cytosol) : Synthétisent les protéines cytosoliques, nucléaires, mitochondriales, peroxysomales.
  • Ribosomes liés au RE rugueux : Synthétisent les protéines destinées à la sécrétion, aux membranes plasmiques, ou aux lysosomes.

💡 Astuce de prof - Règle de localisation :

Le premier acide aminé (signal de localisation) détermine où la protéine ira :

  • Signal peptide N-terminal hydrophobe : → RE rugueux → voie sécrétoire.
  • Pas de signal : → reste dans le cytosol.
  • Signal spécifique (ex: séquence riche en bases basiques) : → noyau, mitochondrie, etc.

6. Modifications Post-Traductionnelles

Après sa synthèse, la protéine subit souvent des modifications pour devenir fonctionnelle :

  • Pliage (folding) : Acquisition de la structure 3D native (assisté par des chaperonnes comme les HSP).
  • Clivage protéolytique : Retrait de séquences (ex: pro-insuline → insuline).
  • Glycosylation : Ajout de glucides (N-glycosylation dans le RE, O-glycosylation dans le Golgi).
  • Phosphorylation : Ajout de groupements phosphate (régulation de l'activité enzymatique).
  • Ponts disulfure : Liaisons covalentes entre cystéines (stabilisation de la structure 3D).
  • Prénylation, acylation, etc. : Ajout de lipides (ancrage membranaire).

PARTIE B : LES ORGANITES EUCARYOTES

Les cellules eucaryotes se caractérisent par leur compartimentation interne : des organites membraneux spécialisés dans des fonctions spécifiques.

1. Le Noyau

Centre de contrôle de la cellule, il contient l'ADN génomique et est le siège de la réplication et de la transcription.

A. L'Enveloppe Nucléaire

  • Double membrane : Membrane interne + Membrane externe (prolongement du RE rugueux).
  • Espace péri-nucléaire : Entre les deux membranes (~20-40 nm).
  • Pores nucléaires : Complexes protéiques (nucléoporines) qui permettent les échanges entre noyau et cytoplasme.
    • Transport passif : Petites molécules (< 40 kDa ou < 9 nm de diamètre).
    • Transport actif : Grosses molécules (protéines, ARN) via des signaux de localisation nucléaire (NLS pour l'entrée, NES pour la sortie). Nécessite de l'énergie (Ran-GTPase).

B. Le Nucléole

  • Fonction : Site de synthèse des ARNr (18S, 5.8S, 28S par la Pol I) et d'assemblage des sous-unités ribosomiques.
  • Structure : Zone dense, non délimitée par une membrane, associée aux régions d'ADN codant pour les ARNr (ADNr).

C. La Chromatine

  • Euchromatine : Décondensée, transcriptionnellement active (gènes exprimés).
  • Hétérochromatine : Condensée, transcriptionnellement inactive (gènes silencieux, régions structurales comme centromères et télomères).

2. Le Réticulum Endoplasmique (RE)

Réseau de membranes interconnectées formant des citernes et des tubules. Deux domaines fonctionnellement distincts :

A. Le RE Rugueux (RER)

  • Structure : Citernes aplaties tapissées de ribosomes sur la face cytosolique.
  • Fonctions :
    • Synthèse des protéines destinées à la sécrétion, aux membranes, ou aux lysosomes.
    • Translocation co-traductionnelle : La protéine en cours de synthèse est injectée dans la lumière du RE via un canal (translocon Sec61).
    • Première maturation :
      • N-glycosylation : Ajout d'un oligosaccharide préformé sur les résidus asparagine (Asn).
      • Formation de ponts disulfure (catalysée par la PDI : Protein Disulfide Isomerase).
      • Pliage assisté par des chaperonnes (BiP, calnexine, calréticuline).
    • Contrôle qualité : Les protéines mal repliées sont rétrodans le cytosol pour dégradation (voie ERAD : ER-Associated Degradation).

B. Le RE Lisse (REL)

  • Structure : Tubules interconnectés, sans ribosomes.
  • Fonctions :
    • Synthèse des lipides : Phospholipides, cholestérol, céramides.
    • Détoxification : Métabolisation des xénobiotiques (drogues, toxines) par les cytochromes P450 (surtout dans les hépatocytes).
    • Stockage du calcium (Ca²⁺) : Crucial pour la signalisation cellulaire (ex: contraction musculaire via le réticulum sarcoplasmique).
    • Métabolisme des glucides : Glycogénolyse (libération de glucose à partir du glycogène).

3. L'Appareil de Golgi

Centre de tri, de maturation finale et de distribution des protéines et lipides provenant du RE.

A. Structure

  • Empilement de saccules (citernes aplaties) délimitées par des membranes.
  • Polarité :
    • Face cis (formation) : Face d'entrée, orientée vers le RE. Reçoit les vésicules de transport du RE.
    • Face trans (maturation) : Face de sortie, orientée vers la membrane plasmique. Envoie des vésicules vers leurs destinations finales.
    • Saccules intermédiaires (médians) : Zones de maturation.

B. Fonctions

  • Maturation des glycoprotéines :
    • O-glycosylation : Ajout de sucres sur les résidus sérine (Ser) ou thréonine (Thr).
    • Modification des chaînes N-glycosylées (ajout/retrait de sucres spécifiques).
  • Sulfatation, phosphorylation, protéolyse : Autres modifications post-traductionnelles.
  • Tri et adressage : Les protéines sont triées selon leur signal de destination et envoyées vers :
    • La membrane plasmique (sécrétion constitutive ou régulée).
    • Les lysosomes (via le signal mannose-6-phosphate).
    • Le RE (rétrotransport).

💡 Astuce de prof - Ordre de la voie sécrétoire :

RE → Golgi (cis → médian → trans) → Membrane plasmique / Lysosomes

Le transport se fait par des vésicules coated (recouvertes de protéines) :

  • COPII : RE → Golgi (anterograde).
  • COPI : Golgi → RE (rétrograde) et entre saccules du Golgi.
  • Clathrine : Golgi trans → Lysosomes / Membrane plasmique (endocytose).

4. Les Lysosomes

Organites de digestion intracellulaire. Ce sont les "estomacs" de la cellule.

A. Structure et Propriétés

  • Vésicules denses (0.1 à 1 µm) délimitées par une membrane simple.
  • pH acide interne (4.5 - 5.0) : Maintenu par des pompes à protons (H⁺-ATPases) dans la membrane lysosomale.
  • Contenu : ~50 hydrolases acides (enzymes actives à pH acide) :
    • Protéases (digestion des protéines).
    • Lipases (digestion des lipides).
    • Glycosidases (digestion des glucides).
    • Nucléases (digestion des acides nucléiques).

B. Fonctions

  • Hétérophagie : Digestion de matériel exogène (bactéries, particules) internalisé par phagocytose ou endocytose → formation de phagolysosomes.
  • Autophagie : Digestion de composants cellulaires endommagés ou obsolètes (organites, protéines agrégées) → recyclage des composants.

💡 Astuce de prof - Pathologies associées :

Les maladies lysosomales (ex: maladie de Tay-Sachs, mucopolysaccharidoses) sont causées par un déficit en une hydrolase lysosomale → accumulation de substrats non digérés dans le lysosome → dysfonction cellulaire.

5. Les Mitochondries

Centres énergétiques de la cellule, elles produisent l'ATP par phosphorylation oxydative.

A. Structure

  • Double membrane :
    • Membrane externe : Lisse, perméable aux petites molécules (porines).
    • Membrane interne : Repliée en crêtes mitochondriales (augmente la surface). Imperméable, contient la chaîne respiratoire et l'ATP synthase.
  • Espace intermembranaire : Entre les deux membranes (pH ~7.0).
  • Matrice mitochondriale : Compartiment interne (pH ~8.0). Contient :
    • Enzymes du cycle de Krebs et de la β-oxydation des acides gras.
    • ADN mitochondrial circulaire (ADNmt).
    • Ribosomes mitochondriaux (55S).
    • ARNt mitochondriaux.

B. Fonctions

  • Production d'ATP : Phosphorylation oxydative (chaîne respiratoire + ATP synthase). Consomme O₂, produit CO₂ et H₂O.
  • Cycle de Krebs : Oxydation complète des métabolites (pyruvate, acides gras) → production de NADH et FADH₂.
  • β-oxydation : Dégradation des acides gras en acétyl-CoA.
  • Apoptose : Libération de cytochrome c → activation des caspases → mort cellulaire programmée.
  • Stockage du calcium (Ca²⁺) : Rôle dans la signalisation cellulaire.

💡 Astuce de prof - Origine évolutive :

La théorie endosymbiotique propose que les mitochondries (et les chloroplastes) proviennent de l'internalisation d'une bactérie aérobie par une cellule hôte ancestrale. Preuves :

  • Double membrane.
  • ADN propre (circulaire, sans histones).
  • Ribosomes propres (type procaryote).
  • Réplication autonome (fission binaire).

6. Les Peroxysomes

Microorganites oxydatifs impliqués dans le métabolisme des lipides et la détoxification.

  • Vésicules simples (0.1 à 1 µm) délimitées par une membrane unique.
  • Contenu : Enzymes oxydatives (catalase, urate oxydase, D-amino acides oxydases).
  • Fonctions :
    • β-oxydation des acides gras à très longue chaîne (VLCFA, >22 carbones).
    • Détoxification du H₂O₂ (peroxyde d'hydrogène) par la catalase : 2 H₂O₂ → 2 H₂O + O₂.
    • Métabolisme des purines et des acides aminés.
    • Biosynthèse des plasmalogènes (phospholipides membranaires, surtout dans le cerveau).
