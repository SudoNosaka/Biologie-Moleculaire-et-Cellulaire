3. La Réplication de l'ADN

Semi-conservative : 1 brin parental + 1 brin néosynthétisé
Sens de synthèse : 5' → 3' uniquement
  • Hélicase : ouvre la double hélice
  • SSB : stabilise les brins simples
  • Primase : synthétise l'amorce ARN
  • ADN Pol III : élongation (procaryotes)
  • ADN Ligase : relie les fragments d'Okazaki
Brin avancé (continu) | Brin retardé (discontinu = fragments d'Okazaki)
Télomérase : ajoute TTAGGG aux extrémités (eucaryotes)

  • Coiffe 5' : 7-méthylguanosine
  • Queue poly-A 3' : signal AAUAAA
  • Épissage : élimination des introns, ligature des exons (spliceosome)
